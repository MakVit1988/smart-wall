Особенности раздвижных перегородок

Главными особенностями конструкций являются высокий уровень звукоизоляции, быстрая трансформация помещения, пожароустойчивость. Все эти критерии учтены в современных раздвижных перегородках для школ от SmartWall.

За быстрое и плавное перемещение секций отвечает потолочное крепление с роликами. Секции, если ￼они не нужны, можно спрятать в специальный паркинг, чтобы они не мешали. Панели секций скреплены между собой надежным петлями, которые не дадут механизму расшататься. Управлять трансформируемыми перегородками для школ сможет даже хрупкая девушка, они легко перемещаются с помощью роликов в потолочном треке.

Разновидности трансформируемых перегородок

За основу конструкции отвечает надежная рама из алюминиевого профиля. Наполнение секций может быть разнообразным. Для своих клиентов мы предлагаем следующие варианты:

  • Стекло (матовое или прозрачное);
  • МДФ-панели;
  • Шпон;
  • Пластик;
  • Магнитно-маркерное покрытие;

Наполнение можно комбинировать, например, нижний ряд секций выполнить из МДФ-панелей, а верхнюю часть ￼заполнить магнитно-маркерным покрытием, добавив дополнительную функциональность конструкции.
