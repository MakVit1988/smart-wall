Предназначение

Их основными задачами является разделение рабочего пространства на отдельные функциональные зоны и создание отдельных рабочих мест. Раздвижные Офисные перегородки помогают выделить и создать:

  • рабочие зоны;
  • конференц-залы для ведения переговоров;
  • кабинеты для совещаний, презентаций и т.д.

Разновидности

Зонировать площадь можно из перегородок различных видов. Их выбор зависит от поставленных задач. По типу конструкций бывают следующие перегородки для зонирования офиса:

  • мобильные – используются для создания отдельных рабочих мест и зон, можно свободно перемещать их с места на место;
  • раздвижные – нужны для объединения или разделения нескольких кабинетов в одно целое или на несколько комнат;
  • стационарные – устанавливаются по заранее намеченной планировке, без возможности переноса;
  • трансформируемые – предусмотрены для нестандартной трансформации помещения в один или несколько функциональных зон.

Для заполнения используется стекло, окраска, ткань, шпон, ЛДСП, HPL-пластик, магнитно-маркерное покрытие. и пр. . Материалы можно соединять между собой в единую конструкцию для создания комбинированных конфигураций. Так, например, к офисной перегородке из стекла часто добавляют МДФ-панели с повышенными акустическими свойствами. Стекло также бывает разным: матовое, закалённое, простое, тонированное и пр.
